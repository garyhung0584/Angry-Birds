# Angry Birds
2025 OOPL [期末專案](./docs/README.md)  
利用 PTSD 框架復刻的初代 Angry Birds

## 專案介紹
本專案為一款基於經典遊戲「Angry Birds」的簡化版模擬遊戲，使用 C++ 開發，利用 [PTSD](https://github.com/ntut-open-source-club/practical-tools-for-simple-design) 作為基礎框架並引入 [Box2D](https://github.com/erincatto/box2d) 物理引擎。  
本專案可透過 **CLion** 編譯與執行，需具備 CMake 支援與必要套件。
